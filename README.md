# INTERLUDE

맥 메뉴바 앱 INTERLUDE의 배포 파일과 업데이트 피드입니다.

**👉 다운로드 페이지: https://zeroruler.github.io/INTERLUDE-releases/**

## 처음 설치하기

1. 오른쪽 **Releases**에서 가장 최신 버전의 `INTERLUDE-x.y.dmg`를 받습니다.
2. DMG를 열고 INTERLUDE를 **응용 프로그램** 폴더로 끌어다 놓습니다.
3. 응용 프로그램 폴더에서 INTERLUDE를 엽니다. "확인되지 않은 개발자" 경고가 뜨면:
   - **시스템 설정 › 개인정보 보호 및 보안**으로 가서
   - 아래쪽 INTERLUDE 항목의 **그래도 열기**를 누르고, 한 번 더 **열기**를 누릅니다.
   - 이 과정은 처음 한 번만 필요합니다.

## 업데이트

앱이 하루에 한 번 새 버전을 확인하고, 있으면 물어봅니다.
직접 확인하려면 **설정 › 일반 › 업데이트 확인**을 누르세요.

> DMG 안에서 바로 실행하거나 다운로드 폴더에 둔 채로 쓰면 업데이트를 받을 수 없어요.
> 꼭 응용 프로그램 폴더로 옮겨서 쓰세요.
